# Built-in media rights inventory

The following product assets currently stored in this repository are embedded in every CLI package. Git history proves their repository provenance, but does not itself prove ownership or external distribution rights. A release owner must replace `REQUIRES_CONFIRMATION` with an approval reference (contract, stock-media receipt, creator assignment, or internal asset ticket) before public or customer distribution.
